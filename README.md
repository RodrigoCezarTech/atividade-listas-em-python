# 📦 Gerenciador de Estoque Simplificado em Python

![Python](https://img.shields.io/badge/python-3.x-blue.svg) ![Status](https://img.shields.io/badge/status-em_desenvolvimento-green.svg)

Um sistema prático e interativo desenvolvido em Python para o gerenciamento de produtos e preços, ideal para fins de aprendizado de estruturas de dados básicas (listas).

## 🚀 Funcionalidades

- **Parte 1:** Visualização completa da lista de produtos cadastrados e seus respectivos preços formatados.
- **Parte 2:** Cadastro em tempo real de novos produtos e preços através de entradas do usuário.
- **Parte 3:** Remoção rápida do último produto cadastrado (operação LIFO - pilha).
- **Parte 4:** Busca e remoção inteligente de um produto específico através do seu nome.

## 🛠️ Tecnologias e Métodos Utilizados

Este projeto explora métodos nativos de listas do Python para manipulação dinâmica de dados:

* `append()`: Adiciona elementos ao final do estoque.
* `pop()`: Remove o último elemento ou um elemento em uma posição específica.
* `index()`: Localiza o índice de um produto pelo nome.
* `zip()`: Permite iterar simultaneamente sobre a lista de produtos e seus respectivos preços.
